# Identidade Visual Printora

Arquivos padronizados:

- `printora-brand-sheet.png`: prancha original com variações da marca.
- `printora-logo-horizontal-color.png`: logo horizontal principal para README, site e telas claras/escuras.
- `printora-logo-horizontal-dark-bg.png`: logo horizontal sobre fundo escuro.
- `printora-logo-horizontal-mono-dark.png`: versão monocromática escura.
- `printora-icon-app-color.png`: ícone quadrado principal para app icon e favicon.
- `printora-icon-symbol-color.png`: símbolo com fundo transparente.
- `printora-icon-app-mono.png`: ícone quadrado monocromático.
- `printora-icon-symbol-mono.png`: símbolo monocromático com fundo transparente.

Paleta aplicada na aplicação:

- Ciano principal: `#12c8d4`
- Ciano escuro: `#0797a5`
- Fundo carvão: `#0c0f12`
- Superfícies escuras: `#14181d`, `#191e24`

Uso recomendado:

- Sidebar/app icon: `printora-icon-app-color.png`
- Favicon: derivado de `printora-icon-app-color.png`
- README/header: `printora-logo-horizontal-color.png`
